# Convert Kilometers to Miles

## Conversion

```text
1 kilometer = 0.621371 miles
```

Therefore:

```text
miles = kilometers × 0.621371
```

## C++ Program

```cpp
class Solution {
public:
    double kmToMiles(double km) {

        // Convert kilometers to miles using the standard
        // conversion factor.
        return km * 0.621371;
    }
};
```

## Example

```text
10 km ≈ 6.21371 miles
```

## Complexity

- Time: `O(1)`
- Space: `O(1)`
